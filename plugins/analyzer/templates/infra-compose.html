Risks & Notes

  • ❌ High PostgreSQL password exposed in .env — consider Docker secrets or a vault for production
  • ⚠ Medium Single-host Docker Compose has no built-in HA — database is a single point of failure
  • ⚠ Medium No horizontal scaling configured for the API service; consider docker-swarm or Kubernetes for scale-out
  • ⚠ Medium Redis has no authentication configured — accessible to any container on backend-net
  • ✓ Low Nginx terminates TLS on port 443 — ensure certificates are auto-renewed (e.g. certbot)
  • ✓ Low Monitoring stack (Prometheus + Grafana) is isolated on monitoring-net — no external exposure
